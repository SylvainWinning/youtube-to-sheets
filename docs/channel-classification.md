# Classement des chaînes des playlists

État du catalogue vérifié le 10 octobre 2026 : 110 chaînes, 627 entrées dans Playlist principale et Vrouuum. Toutes ont une catégorie; les choix existants sont conservés.

Le classement suit le contenu des chaînes et des vidéos enregistrées. Pause dej regroupe notamment les entretiens et podcasts; Youtuber pref reste un choix personnel. Kyan Khojandi y a été ajoutée à la demande de l’utilisateur. Sa préférence concerne Hardisk TV, déjà classée dans Youtuber pref; Hardisk reste dans Pause dej. Hardisk TV ne figure pas dans cet instantané des playlists. Ce document est un instantané; le test de couverture vérifie les exports lors des changements futurs.

## Vérification

Les deux exports, public et cache de synchronisation, sont couverts par un test exigeant une catégorie nommée pour chaque chaîne. Le classement précède la recherche et le filtre; les données source ne sont plus modifiées par le menu catégories. Une catégorie personnelle définie sur une vidéo reste prioritaire.

Pour les cas ambigus, les sujets des vidéos du catalogue servent de base. Sources complémentaires : [Comportements / HeySamy](https://heysamy.fr/) pour le marketing; [vidéo de Kasper](https://www.youtube.com/watch?v=VQvIvvZxk10) pour le trading. Ces placements éditoriaux peuvent être ajustés sans changer les vidéos ni les playlists.
